This is a simple **FAQ (Frequently Asked Questions) web page** built using **HTML, CSS, and JavaScript**.  
It displays questions dynamically and allows users to expand/collapse answers.

## Features

- Dynamic FAQ generation using JavaScript  
- Click to expand/collapse answers  
- Only one question opens at a time  
- Smooth animation effect  
- Clean and simple UI  


## Tech Stack

- HTML5  
- CSS3  
- JavaScript  



## How it Works

- Questions and answers are stored in JavaScript objects  
- Each FAQ item is created dynamically using DOM  
- Clicking a question:
  - Opens the selected answer  
  - Closes other open answers  
  - Toggles (+ / -) icon  


##  How to Run

1. Download or clone the repository  
2. Open the folder  
3. Open `index.html` in your browser
